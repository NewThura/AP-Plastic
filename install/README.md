# Windows setup (only if the Install button can't be used)

The easy way to install AP Plastic ERP is the **Install app** button at the top of the app (Chrome or Edge,
on a computer or an Android phone; on iPhone use Safari > Share > Add to Home Screen).

For a Windows computer where that doesn't work, copy this folder to the computer and double-click
`Install AP Plastic ERP.bat`. It makes a Desktop and Start menu icon that opens the app in its own window.
Nothing else is installed; the records stay in Supabase.
