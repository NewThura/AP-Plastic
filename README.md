# AP Main

The owner's app for AP Plastic: Overview, Sales, Production, Computers and Settings, in Myanmar and English.
It keeps records on the office PC and in the company cloud (Cloudflare, code in `cloud/`).

Open `index.html` in Chrome or Edge (the desktop shortcut "AP Plastic" does this).
To install it on a computer: copy this folder there and double-click `install\Install AP Main.bat`.
Read `CLAUDE.md` before working on it.

This branch (`new-app`) holds AP Main only. The old AP ERP is a different app on branch `main`.
